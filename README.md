## Documentation
Automatically updated documentation available on [Read the Docs](https://dublib.readthedocs.io/ru/latest). Build insctructions you can find [there](https://github.com/DUB1401/dublib/tree/main/docs).

All functions, classes and methods in **dublib** provides detailed docstrings in [Sphinx](https://www.sphinx-doc.org/en/master) format. Use it in development process on the fly.

## Available modules
- **cli** – instruments kit to make CLI applications and stylize text in terminal.
- **engine** – talking bus, configs operator, patcher and localisation helper.
- **functions** – functions to data processing and transformation, unified system calls, decorators.
- **polyglot** – simple formatters for _Markdown_ and _HTML_.
- **validators** – validators and parsers for string-type data.
- **web_requestor** – WEB-requests operator, that unified work with [requests](https://github.com/psf/requests), [httpx](https://github.com/encode/httpx) and [curl_cffi](https://github.com/lexiforest/curl_cffi) libs and add many automations.
